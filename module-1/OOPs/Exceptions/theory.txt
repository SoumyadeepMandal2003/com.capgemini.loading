Try:
    What it does:
        It contains code that might cause an error.

    Why is it useful:
        To prevent program from crashing if something goes wrong

-------------------------------------------------------------------------------------------------------------

Catch:
    What it does:
        It catches the error that happens in the try block and handles it.
    Why is it useful:
        Instead of crashing, your program can show a message or do something safe.

-------------------------------------------------------------------------------------------------------------

Finally:
    What it does:
        It always runs whether there was a error or not.

    Why is it useful:
        To do cleanup work like closing files, releasing memory,
